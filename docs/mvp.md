# 1차 MVP 범위와 PR 계획

Windows에서 사용자가 부품으로 회로를 그리고, 저장한 회로를 설정한 시간 간격으로 실행하고, 별도 창에서 기준 파형과 비교할 수 있게 한다. 첫 설계 판단은 계산 결과를 신뢰할 수 있는지와 긴 파형을 원본 정보 손실 없이 탐색할 수 있는지에 둔다. 아래 항목은 구현 계획이며 수치 목표는 측정 전 제안값이다.

## 사용 흐름과 완료 조건

1. 리치오의 Activity bar처럼 **탐색기**와 **부품 라이브러리**를 전환한다. 탐색기에서 폴더와 파일을 만들고 이름 변경·이동·삭제할 수 있다. 주 화면에 여러 회로를 탭으로 열며, 파일별 선택·변경 표시·Undo 기록을 유지한다. 열린 파일의 이름을 바꾸거나 저장하지 않은 탭을 닫을 때 작업 내용을 보호한다. 공통 색상·타이포그래피·키보드 포커스·활성 탭 표시는 리치오의 역할별 토큰을 Qt에 대응시킨다.
2. 부품을 클릭하면 현재 뷰의 빈 격자점에 추가하고 드롭하면 놓은 위치에 추가한다. 이동·회전·값 편집·배선·Undo가 가능하다. 시작 부품은 DC/정현파 전압원, R·L·C, 기준 접지, 다이오드, 바디 다이오드가 있는 N채널 MOSFET, 펄스/PWM 게이트 구동, 전압·전류 프로브다. 부품 정의에서 단자 ID·방향·파라미터·기호를 연결한다. 여기서 에디터는 이 부품을 사용해 회로를 작성하는 편집기를 뜻한다. 사용자가 새 소자 방정식과 기호를 저작하는 기능은 별도 범위로 제안한다.
3. 기호 크기·단자 피치·배선 통로·평행 가지 간격을 공통 격자의 정수 배로 정의한다. 회전해도 단자가 격자에 남고, 부품 이동 시 주변 직각 배선만 조정한다. 전기적 분기에는 접속점을 표시하고 단순 교차는 연결하지 않는다. 벅과 2상 PFC 대표 도면에서 기호 관통, 무관한 배선의 중첩, 숨은 접점, 불필요한 꺾임을 검사하고 원래 크기의 화면도 검토한다. 조밀한 임의 회로에는 수동 꺾임점 편집을 제공한다.
4. 버전이 있는 UTF-8 JSON을 `*.litzsim`으로 저장한다. 소자·단자 ID, 네트의 단자 목록, 프로브 극성, 단위와 값, 제어 연결, 초기조건과 시뮬레이션 설정을 명시한다. 도면 좌표·꺾임점은 별도 필드에 둔다. 미완성 회로도 저장할 수 있고, 실행할 때 누락된 단자나 설정을 해당 ID로 안내한다. 저장·재열기 후 GUI와 CLI가 같은 연결을 읽는지, 텍스트만 읽어도 AI가 두 단자의 연결과 전류의 양의 방향을 답할 수 있는지 검사한다.
5. 상단에서 종료 시각·기본 time-step을 설정하고 실행·중지한다. 적분 간격, PWM 전환, 제어 샘플, 결과 저장 간격을 구분한다. 현재 회로와 설정의 스냅샷을 각 실행에 연결해 실행 후 회로를 수정해도 기존 결과를 재현할 수 있게 한다.
6. 독립 결과 창에서 엔진 출력과 외부 CSV를 열고 여러 plot을 추가·삭제한다. 시간 또는 신호를 X축으로, 한 개 이상의 신호를 좌·우 Y축으로 선택한다. 축별 자동·수동 범위, 확대·축소·이동·전체 보기, 실행 간 겹쳐 그리기를 지원한다. 원래 시간축과 단위를 보존하고, 시간 plot들은 선택적으로 X축을 동기화한다.

## 9개 PR

| 순서 | 산출물 | 로컬 인수 기준 |
| --- | --- | --- |
| 1 | C++ 공통 코어, 부품 정의, 파일 규격·예제 | GUI 없이 RC·벅 파일을 읽고 다시 저장한다. 연결·극성·초기조건이 보존되고 위치만 바꿔도 네트는 동일하다. |
| 2 | 헤드리스 실행기와 RC·RLC 기준 시험 | 회로 파일에서 방정식을 구성한다. 해석해 대비 오차와 time-step 절반화에 따른 수렴을 기록한다. |
| 3 | PWM·이상 MOSFET·다이오드와 벅 시험 | 연속·불연속 전도에서 구간별 기준해와 전류 리플, 영전류 시각, 정류 차단 및 에너지 수지를 비교한다. |
| 4 | 대용량 결과 저장·CSV 읽기와 성능 시험 | 분할 읽기, 가시 구간 조회, 시간축 표시용 최소·최대 요약을 시험한다. 블록 경계의 단일 샘플 피크와 원본 조회값을 보존한다. |
| 5 | Qt 앱, Activity bar, 탐색기·라이브러리·문서 탭 | 두 파일을 열고 폴더 이동·이름 변경·저장·재열기를 수행한다. 탭 간 편집 상태가 섞이지 않는다. |
| 6 | 격자 기반 회로 편집기와 직각 배선 | 빈 문서에서 클릭·드롭으로 벅을 작성한다. 이동·회전·분기·교차·Undo 전후의 단자 연결과 대표 도면의 배치를 확인한다. |
| 7 | 시뮬레이션 설정, 상단 실행·중지, 결과 인계 | 같은 파일·설정의 GUI/CLI 결과를 비교한다. 연속 실행과 중지 시 결과 상태와 실행 출처를 식별할 수 있다. |
| 8 | Simview 방식의 독립 파형 창 | 복수 plot, XY, 좌·우축, 확대·이동, 다른 실행·CSV 겹치기를 실제 조작한다. PR 4의 대용량 데이터로 화면 응답과 피크 보존을 다시 측정한다. |
| 9 | 2상 PFC 기동 예제와 종단 간 검증 | 편집기에서 수정한 회로를 실행해 결과 창에서 스위칭·평균 파형을 비교한다. 동일 제어기·초기조건·부하의 실행 기록, 정량 오차, 실행시간과 미검증 범위를 남긴다. |

PR 1–3에서 먼저 해석 신뢰성을 판단한다. PR 4는 PR 1의 신호·단위·시간축 규약이 정해지면 합성 데이터로 앞당겨 시험할 수 있다. PR 9에는 2상 PWM과 샘플 제어, 동일 제어기를 쓰는 평균 모델, DC/DC 대체 부하를 포함한다. 정상·과도 운전 전체로 정확도를 일반화하지 않는다. 전체 OBC 결합, CLLLC EDF, 사용자 DLL, AI 자율 편집은 후속 대상이다. 이 계획의 검증은 로컬 명령·결과 기록으로 진행하며 GitHub CI 도입은 보류한다.

## 성능·정확도 판정

### 화면 변경 검토

Qt 화면을 바꾸는 PR에서는 동일한 논리 해상도와 배율의 리치오 실행 화면과 LitzSim 빌드 캡처를 비교한다. 리치오 버전·커밋, 실행 환경(설치판 또는 웹 에디터), 테마, 언어, 활성 탭, 펼친 패널을 기록한다. Activity bar 폭과 아이콘·선택 표시, 탐색기 제목과 행 간격, 활성·미저장 탭, 한글·숫자 글꼴, 키보드 포커스를 확인한다. 회로도에서는 단자·측정 방향, 파형 창에서는 축·범례·피크 가독성을 별도로 본다. 화면 차이마다 수정 가능한 구현 차이, 회로 작업에 필요한 의도적 차이, 재현된 스택 제약, 미검증 중 하나와 근거를 적고 전후 이미지를 보여준다. 설치판에서 확인하지 않은 OS 제목 표시줄·DPI·글꼴 래스터화 차이는 미검증으로 남긴다.

- **파형 성능 후보 기준** — Windows 기준 PC의 CPU·RAM·SSD·화면 해상도와 Release 빌드를 기록한다. 동일한 1,000만 행 × 8개 신호와 시간 열을 엔진 출력·CSV 두 형식으로 준비한다. 최초 CSV 읽기와 인덱스 생성, 준비된 결과 재열기, 첫 화면 표시, 최대 메모리를 따로 측정한다. 우선 목표는 준비된 결과의 첫 화면 2초 이내, 4개 시간 plot 이동·확대 시 프레임 시간 p95 33 ms 이하다. 원본은 파일에 보존하고 통계는 원본에서 계산한다. 비단조 X축을 쓰는 XY 궤적은 시간 순서와 루프 보존을 별도로 검사한다.
- **해석 정확도** — 회로별 기준해·측정 구간·허용오차를 결과 확인 전에 정한다. RC·RLC와 벅의 독립 기준 시험을 통과한 뒤 PFC로 확대한다. PFC의 선행 조건과 모델 간 RMSE는 [전력단 모델과 검증 기준](spikes/2026-11-25-converter-models.md)을 참조한다. 외부 기준 파형 확보 여부와 시각 대조·정량 비교 여부를 구분해 기록한다.
