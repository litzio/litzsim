# 리츠심의 목적

전력전자 엔지니어가 회로를 눈으로 읽고 직접 바꾸며, AI에게도 같은 회로의 구성·실행·분석을 맡길 수 있게 한다. 두 사용자는 같은 소자, 같은 단자, 같은 전류 방향을 가리킬 수 있어야 한다.

첫 시스템은 **계통 ↔ 인터리브드 토템폴 PFC ↔ DC-Link ↔ CLLLC ↔ 배터리**다. 입력 필터를 추가하거나 전류 제어기를 바꿀 때 주변 회로를 다시 작성하지 않아도 되는 수준의 조합성을 목표로 한다. 사용자는 [Litzio](https://github.com/litzio/litzio) 안의 플러그인으로 LitzSim을 쓴다. Litzio 위에서 회로 편집·시뮬레이션·파형 보기가 막힘없이 쾌적한 것이 최우선이다.

## Litzio 플러그인 우선

2026-11-26 소유자 결정. 단독 실행판은 지금 만들지 않는다. 나중에 LitzSim을 따로 배포하게 되면 앱 껍데기를 씌워 넓힌다. 그때 핵심을 다시 만들지 않도록 다음 경계를 지킨다.

1. Rust 코어(회로 문서, 편집 연산, 해석, 도면 배치, 파형 조회)는 Litzio 코드나 SDK에 의존하지 않고 CLI만으로 동작한다.
2. 화면은 얇은 어댑터 한 겹을 거쳐서만 Litzio 기능(파일 선택, 작업 호출, 설정)을 부른다.
3. 회로(`.litzsim`)와 실행 결과(`runs/`)는 사용자 폴더의 LitzSim 파일로 둔다. Litzio 문서나 Host 내부 저장소에 넣지 않는다.
4. 핵심 기능은 Litzio 비서에 의존하지 않는다. AI는 CLI 위에서 같은 연산을 쓴다.

Litzio의 디자인(색, 글꼴, 부품 모양)은 따른다. 재구축 계획과 검증 기준은 [Rust 재구축](rebuild.md)에 있다. C++·Qt 1차 MVP의 범위는 [1차 MVP 범위와 PR 계획](mvp.md)(보관)에 있다.

## 이후 AI 공동 편집 시연에서 해볼 일

1. 엔지니어가 회로도에서 입력 가지를 선택하고 그 위치에 LC 필터를 추가한다. 기존 두 상의 부품 배치를 보존한다.
2. AI가 필터 앞 계통전류와 필터 뒤 두 인덕터 전류의 측정 위치·극성을 읽는다. 엔지니어가 변경된 접속을 확인하고 한 번에 되돌릴 수 있다.
3. 같은 제어기와 지령으로 기동을 실행하고 스위칭 주기 평균전류와 DC-Link 전압을 비교한다. 실행별 설정과 원래 시간축을 보존한다.

제품 설명에는 해당 저장소에서 실제 실행하고 확인한 기능을 표시한다.
