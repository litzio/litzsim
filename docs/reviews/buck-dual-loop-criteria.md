# 이중루프 벅 PR 본문 초안

Closes #82

## 변경과 설계 근거

- 12 V → 5 V, 100 kHz 이상 벅에 외부 전압 PI, 전류 지령 리미터, 내부 전류 PI, 주기 시작에서 듀티를 고정하는 PWM을 연결한다. 두 루프는 10 µs마다 같은 시각에 갱신한다.
- L = 100 µH, C = 220 µF, C의 ESR = 0 Ω. 2.5 Ω 부하에 6 ms부터 5 Ω을 병렬 연결한다. 5 V에서 2 A → 3 A이고, 정상 듀티 5/12에서 예상 인덕터 리플은 약 0.29 A p-p다.
- 0 V에서 시작하는 2 ms, 5 V 소프트스타트 램프를 적용한다. 초기 인덕터 전류는 0.25 A, 초기 커패시터 전압과 PI 적분 상태는 0이다. 전류 지령은 0.25–4 A로 제한해 기동 중 환류를 확보하고 3 A 부하에서 회복 여유를 둔다. 전압 PI의 자체 출력 한계도 같게 두어 리미터에서 걸리는 포화를 PI가 알 수 있게 한다. 전류 PI 듀티 한계는 0–0.9다.
- 전류 루프의 고주파 근사 플랜트는 Vᵢₙ/(Ls)다. 목표 5 kHz에서 Kp ≈ 2π·5000·L/Vᵢₙ = 0.262, 500 Hz 영점으로 Ki ≈ 823을 쓴다. 전압 루프는 닫힌 전류 루프를 단위 이득으로 근사하고 1/(Cs)에서 목표 800 Hz로 Kp ≈ 2π·800·C = 1.106, 300 Hz 영점으로 Ki ≈ 2085를 쓴다. 이 값은 초기 이득 산정이며 실측 교차 주파수는 검증 범위 밖이다.

## 결과 확인 전 합격 기준

- 0–12 ms, 기본 적분 간격 0.1 µs, 에지 포함 모든 적분 결과를 기록한다. 시작부터 종료까지 인덕터 전류가 양수여야 한다. 5–6 ms와 10–12 ms에서 출력 평균은 5 V ±25 mV, 인덕터 평균은 저항 부하 평균과 ±5 mA 이내여야 한다. 두 창은 샘플 경계로 맞추며 부하 전류는 창의 출력 평균을 해당 등가 저항으로 나눈다.
- 평균 벅 기준은 dI/dt = (12D − V)/L, dV/dt = (I − V/R)/C로 독립 구현한다. 예제와 같은 PI 차분식·레일·샘플·초기조건을 사용하며, 매 주기 80개 고정 RK4 스텝과 사다리꼴 평균을 쓴다. 스위칭 파형은 주기 경계에서 왼쪽·오른쪽 극한을 보존하여 시간 적분한다.
- 6–12 ms의 600개 주기에서 기본 해와 평균 기준의 RMSE 한계는 출력 전압 50 mV, 인덕터 전류 200 mA, 듀티 0.05다. 평균 모델은 리플을 제거해 전류 샘플에서 최대 반 리플(약 0.146 A)의 차이가 생길 수 있다. 전압과 듀티 한계는 5 V의 1%, 5 퍼센트포인트다.
- 주기 평균 언더슈트는 5 V에서 6 ms 이후 최소값을 뺀 값이며, 스위칭 해는 300 mV 이하, 평균 기준과 차이는 75 mV 이하다. 회복은 5 V ±50 mV 안에 들어와 종료까지 머무는 첫 완전한 주기의 시작을 기준으로 잰다. 스위칭 해는 부하 전환 후 2 ms 이내, 평균 기준과 차이는 0.3 ms 이내다. 75 mV와 0.3 ms는 각각 허용 강하의 1/4, 목표 외부 루프 시정수(약 0.2 ms)의 약 1.5배다.
- 0.2 → 0.1 → 0.05 µs에서 전 구간 주기 평균 결과를 비교한다. 출력 전압·인덕터 전류·듀티 각각에서 더 미세한 두 해의 차이 RMSE는 더 거친 두 해 차이의 80% 이하여야 한다. 1차 적분에서 기대하는 50% 감소율에 에지 분할과 제어 포화 경계의 여유를 둔다.
- main의 기존 예제 7종은 파형 파일 전체 바이트가 같아야 한다. 보관 PFC 입력은 기존 거절 결과를 대조한다. Windows GNU Release 빌드·전체 테스트와 웹 플러그인 검사, 격리 Litzio Host의 회로와 세 파형 채널을 확인한다.

## SOC 1단계 추가 합격 기준

- 5–6 ms와 10–12 ms의 각 정상상태 창에서 인덕터 전류 주기 평균과 같은 창의 전류 지령 평균 차이는 ±5 mA 이하다. 앞서 고정한 출력 전압, 전류 균형, CCM, 부하 계단, 독립 평균 모델 비교 및 스텝 수렴 한계를 유지한다.
- 이상 CCM 벅의 출력을 이상 전압원으로 고정하고 전압비와 듀티를 같게 둔다. 켜짐 기울기는 (Vin − Vout)/L, 꺼짐 기울기는 −Vout/L이다. 주기 시작, 켜짐 중앙, 켜짐 끝 직전의 해석 전류에 각각 절대 오차 1 µA를 허용한다. 두 구간의 선형 기준해에서 산술 오차를 수용하는 한계다.
- SOC나 태스크 실행에 종료 시각을 일치시키고 위아래로 1 ULP 이동해 이벤트 적용 여부와 진단을 비교한다. 에지와 SOC가 겹치면 왼쪽 값을 잡는다. 듀티 0과 1에서 길이 0인 구간의 SOC는 해당 구간의 경계다.
- 기록 간격과 채널 기록 설정을 바꿔도 공유 시각의 공통 신호와 진단이 같다. 전기 전용 예제 5종의 파형 파일 전체는 변경 전 main과 바이트 단위로 일치한다.
